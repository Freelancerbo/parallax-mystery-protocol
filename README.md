# PARALLAX: The Mystery Protocol

A real-time multiplayer social deduction game for 4–8 players. Players join with a room code, receive secret roles, vote on mission teams, solve challenges, and try to expose the NEXUS agents.

## Features

- Room creation and joining with a six-character code.
- 4–8 players, no player accounts required.
- Host-controlled game launch and mission progression.
- Server-assigned hidden roles: Resistance and NEXUS.
- Public chat and private NEXUS chat.
- Team proposals, synchronized voting, mission actions, sabotage, and live results.
- Five missions and multiple endings.
- Responsive dark cyberpunk interface.
